# Raw Requirements
 
## RF24: Alta de una materia
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe ser capaz de generar el alta de una materia |
| **Actor** | Administrador Global o Administrador de Unidad |
| **Entrada** | El administrador ingresa a Gestión
Dentro del cuadro Materias, selecciona Alta de Materia
Ingresa:
Nombre de materia
Cantidad de horas semanales
Dependencia
Unidad
Año/s Educativo
Despliegue
N° de Plan de Estudio  |
| **Condición** | La materia no debe existir previamente |
| **Salida** | Queda registrado el cambio en el sistema, mostrando un mensaje de confirmación.   |
