# Raw Requirements
 
## RF21: Alta de una cátedra
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe ser capaz de generar el alta de una cátedra |
| **Actor** | Administrador Global o Administrador de Unidad |
| **Entrada** | El administrador ingresa a Gestión
Dentro del cuadro Cátedras, selecciona Alta de Cátedra
Ingresa:
Nombre de cátedra
Tipología
Director de Cátedra
Materia  |
| **Condición** | La cátedra no debe existir previamente
El campo de Estado se carga automáticamente como “Activo” (sus dos posibles estados son “Activo” o “de Baja”) |
| **Salida** | Queda registrada la nueva cátedra en el sistema, quedando en estado “Activa”.  |
