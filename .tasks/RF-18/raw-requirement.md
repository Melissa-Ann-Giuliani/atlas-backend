# Raw Requirements
 
## RF18: Modificar los datos de un cargo
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe ser capaz de modificar los datos de un cargo |
| **Actor** | Administrador Global o Administrador de Unidad |
| **Entrada** | Accede a Gestión
Dentro del cuadro Cargos, selecciona Modificación de cargo
El administrador busca el cargo por Número de cargo, fecha de creación o estado
Selecciona el botón de Editar
Cambia los valores que desee |
| **Condición** | El cargo debe existir previamente |
| **Salida** | Queda registrado el cambio en el sistema, mostrando un mensaje de confirmación.  |
