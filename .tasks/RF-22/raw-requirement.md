# Raw Requirements
 
## RF22: Modificar los datos de una cátedra
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe ser capaz de modificar los datos de una cátedra |
| **Actor** | Administrador Global o Administrador de Unidad |
| **Entrada** | El administrador ingresa a Gestión
Dentro del cuadro Cátedras, selecciona Modificación de Cátedra  |
| **Condición** | La cátedra debe existir previamente |
| **Salida** | Queda registrado el cambio en el sistema, mostrando un mensaje de confirmación.  |
