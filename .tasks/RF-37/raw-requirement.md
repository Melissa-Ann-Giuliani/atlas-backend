# Raw Requirements
 
## RF37: Permitir la re-designación para el docente con su designación por vencer de forma simple
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe ser capaz de permitir la re-designación para el docente con su designación por vencer de forma simple. |
| **Actor** | Administrador Global o Administrador de Unidad |
| **Entrada** | El administrador ingresa a Gestión, selecciona Vencimientos
Elige al docente con designación a vencer de entre la lista de vencimientos próximos |
| **Condición** | Debe existir una alerta de vencimiento activa sobre la designación  |
| **Salida** | Se extiende o genera la nueva designación del docente, y el alerta de vencimiento correspondiente se desactiva. |
