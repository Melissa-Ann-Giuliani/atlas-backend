# Raw Requirements
 
## RF23: Baja de una cátedra
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe ser capaz de generar la baja de una cátedra |
| **Actor** | Administrador Global o Administrador de Unidad |
| **Entrada** | El administrador ingresa a Gestión
Dentro del cuadro Cátedras, selecciona Baja de Cátedra  |
| **Condición** | La cátedra debe existir previamente |
| **Salida** | Queda registrado el cambio en el sistema en estado “De baja”, mostrando un mensaje de confirmación de operación.   |
