# Raw Requirements
 
## RF26: Baja de una materia
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe ser capaz de generar la baja de una materia |
| **Actor** | Administrador Global o Administrador de Unidad |
| **Entrada** | El administrador ingresa a Gestión
Dentro del cuadro Materia, selecciona Baja de Materia  |
| **Condición** | La materia debe existir previamente |
| **Salida** | Queda registrado el cambio en el sistema, mostrando un mensaje de confirmación.   |
