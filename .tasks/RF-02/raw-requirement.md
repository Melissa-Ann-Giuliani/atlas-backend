# Raw Requirements
 
## RF02: Mostrar un mensaje de error con datos de log in incorrectos
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe mostrar un mensaje de error si el usuario o la contraseña son incorrectos. |
| **Actor** | Usuario |
| **Entrada** | Nombre de usuario y contraseña |
| **Condición** | El nombre de usuario o contraseña ingresado no coincide con un nombre de usuario o contraseña ya guardado en la base de datos. |
| **Salida** | Mostrar un mensaje de error indicando en cuál de los dos datos se ha equivocado. |
