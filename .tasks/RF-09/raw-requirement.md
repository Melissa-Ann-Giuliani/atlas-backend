# Raw Requirements
 
## RF09: Registrar las designaciones de docentes
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe permitir registrar las designaciones correspondientes a cada docente |
| **Actor** | Administrador Global, Administrador de Unidad |
| **Entrada** | Administrador ingresa a Trámites
Selecciona Designaciones de entre las opciones en pestañas
Ingresa:
N° de Legajo, N° de Resolución, o Apellido y Nombre del Docente
Fecha de comienzo
Fecha de finalización (es posible dejar este campo vacío) |
| **Condición** | Si el docente no se encuentra, puede ser redirigido al ingreso de nuevos docentes |
| **Salida** | Queda registrado en el sistema la designación del docente, generando la documentación adecuada, vinculándola al docente, y dando la posibilidad de imprimir dicha documentación.
El docente es notificado sobre su designación aprobada, quedando en el sistema con el nuevo estado “Activo”  |
