# Raw Requirements
 
## RF01: Autenticar con nombre de usuario y contraseña
 
| Campo | Detalle |
|---|---|
| **Descripción** | El sistema debe permitir autenticarse con nombre de usuario y contraseña. |
| **Actor** | Usuario |
| **Entrada** | Nombre de usuario y contraseña |
| **Condición** | El nombre de usuario y contraseña ingresado coincide con un par ya guardado en la base de datos, y el usuario tiene estado "Activo". |
| **Salida** | Ingresar al sistema, redirigiendo a la pantalla principal correspondiente a su rol. |
